# Installation
To install this mod, you must unzip the content and place it in:

## Epic Game
C:\Program Files (x86)\Steam\steamapps\common\The Lord of the Rings Return to Moria™\Moria\Content\Paks

## Steam
C:\Program Files\Epic Games\ReturnToMoria\Moria\Content\Paks

## Custom installation
Find where you installed the game and follow the same path as Epic Games or Steam from previous options.
